# Proyecto 1 - Gestión de pedidos

API REST con Spring Boot para terminales, categorías, productos y pedidos.

## Tecnologías
Java 21, Spring Boot, Spring Web, Spring Data JPA, MySQL, Lombok y SpringDoc OpenAPI.

## Arranque
1. Crear la base de datos `gestion_pedidos`.
2. Copiar `.env.example` a `.env`.
3. Completar las credenciales de MySQL.
4. Abrir con IntelliJ y ejecutar `GestionPedidosApplication`.

Swagger: http://localhost:8080/doc/swagger-ui.html
